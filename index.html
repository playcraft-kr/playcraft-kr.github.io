What is PlayCraft?

PlayCraft is a home for original browser games made by young creators. Tap a tile and the game starts right away. Nothing to download, no account needed.

Soon you will be able to send in your own game and leave ideas on other games. When an idea is picked, it goes into the next version, and the version history credits the player who suggested it.

  1. Make it and send it inAny game that runs as a single HTML file (coming soon)
  2. Admin reviewAn admin plays it first, then publishes it to the site
  3. Upgrade ideasPlayers suggest ways to make the game more fun (coming soon)
  4. Pick → upgradeThe best ideas ship in the next version
